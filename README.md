# SLATE v2

A from-scratch rebuild of SLATE, a tile-based roguelike (Python + pygame-ce,
Lua/`lupa` for scriptable content, a fully data-driven JSON content
pipeline, and an in-house content editor).

This repository currently holds the **build documentation**, not yet the
implementation. Start at [`docs/ORCHESTRATION.md`](./docs/ORCHESTRATION.md)
for how the build is organized into independent, parallelizable component
sessions, and [`docs/README.md`](./docs/README.md) for the full doc index.
